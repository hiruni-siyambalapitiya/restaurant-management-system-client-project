# 🍽️ Restaurant Management System

 A full-stack Restaurant Management System developed using the MERN Stack to automate restaurant operations including customer ordering, inventory management, reporting, delivery, and staff administration.
 
 https://github.com/hiruni-siyambalapitiya/restaurant-management-system-client-project/blob/main/screenshots/first%20page.png

---

## 📌 Project Overview

This project was developed as a university software engineering project for a restaurant client.

The system replaces manual restaurant operations with an integrated digital platform that improves operational efficiency, inventory tracking, customer experience, and business reporting.

https://github.com/AchinthaDavidson/Restaurant-Management-System-Admin-Panel.git

---

# Business Problem

The restaurant faced several operational challenges:

- Manual order handling
- Inventory wastage
- No online ordering platform
- No delivery management
- Limited reporting capabilities
- Difficult-to-use desktop software

The proposed solution was a web-based Restaurant Management System developed using the MERN Stack.
